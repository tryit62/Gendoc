GÉNÉRATEUR DOCUMENTAIRE DE L'ORDRE — V1

1. Ouvrir index.html dans un navigateur moderne.
2. Choisir dossier, catégorie, classification et métadonnées.
3. Remplir le contenu restant.
4. Utiliser IMPRIMER / PDF pour produire le document.
5. Le brouillon peut être sauvegardé localement dans le navigateur.

Compatible avec un hébergement GitHub Pages : déposer index.html à la racine du dépôt.
Aucune donnée n'est envoyée sur Internet par cette V1.
